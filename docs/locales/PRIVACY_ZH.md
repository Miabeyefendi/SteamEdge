# 🔐 安全与你的 Steam 登录

> [!WARNING]
> **SteamEdge 可以代你操作 Steam 账号：集卡、挂时长、解锁成就、在市场上架物品。下面如实说明它如何处理你的登录、把登录信息存在哪里、会向网络发送什么，方便你判断自己是否放心使用。**

| 项目 | 说明 |
|---|---|
| **密码** | 在登录界面输入后，通过 HTTPS 直接交给 Steam 自己的登录服务，只在这次调用期间留在内存中。**绝不会写入磁盘**，也不会写入日志。 |
| **Steam Guard 验证码** | 只向 Steam 发送一次，随后丢弃，不保存。应用不持有你的验证器密钥（旧的 maFile 功能已在 1.1.9 移除），因此无法替你批准手机确认。 |
| **会话令牌** | 登录后 Steam 会给应用一个刷新令牌，以免再次询问。它不是你的密码。保存在 exe 旁边的 `settings/session.json` 和 `settings/accounts.json`。**默认是明文。** 开启 *設定 > 隱私與安全 > 加密登入權杖* 后，会用 Windows DPAPI 加密，只有这台电脑上你的 Windows 用户能读取。网页 Cookie 只存在内存中。 |
| **Cookie 登录（备用方式）** | 如果用 Cookie 登录而不是正常登录，`settings/web-session.json` 会以明文保存这些 Cookie，直到你退出登录。 |
| **日志文件** | `logs/` 记录事件（`steamedge.log`）、Steam 连接的断开与恢复（`connection.log`）以及意外错误（`crash.log`），不会记录密码、令牌或 Cookie。 |
| **导出** | 设置导出不包含令牌、代理地址（含密码）和家长控制 PIN。 |

**会向网络发送什么**

- **Steam 本身**：与 Steam 客户端相同的连接（登录、聊天、“正在游戏”状态），通过 `steam-user` 和 `steam-session` 库。
- **`steamcommunity.com`**：库存、市场、上架和成就页面，使用你的会话。
- **`api.steampowered.com`**：登录和会话调用。
- **`*.steamstatic.com`**：游戏图片和 Steam 自己的市场手续费脚本（在隐藏的沙盒窗口中运行，没有 Node 权限）。
- **`api.github.com`**：启动时一次，以及你点击更新按钮时，用来读取公开的版本列表。不会发送任何关于你的信息，也不会下载或安装任何东西。
- **你自己的代理**，仅当你为账号或登录设置了代理时。
- 除此之外没有别的。**没有我的服务器，没有统计分析，没有遥测，没有崩溃报告，没有广告。** 字体已内置，所以也不会访问字体服务器。

**出售**：上架请求发送到 Steam 市场的方式与网站相同。开启手机验证器后，每一笔上架都要等你在 Steam 应用里批准，SteamEdge 无法代为批准。应用会隔开请求（至少间隔 1.5 秒），并且绝不会重复发送同一件物品。

**应用窗口如何被锁定**：它只能加载自己的文件，不能打开网页，窗口内部关闭了 Node 权限（上下文隔离和内容安全策略）。

**如何自行验证**：代码开源（AGPL-3.0），每次改动都经过 CodeQL 扫描，每个发布文件的 SHA-256 都会公布，你也可以用 `npm run build` 自己编译。

**保护自己**
- 不要分享你的 `settings/` 文件夹（压缩包、截图、求助请求），里面可能有你的令牌。
- 开启令牌加密（见上），在某台电脑上不再使用时请点击 *登出*。
- 若要让所有已保存的会话失效，请使用 Steam Guard 设置里 Steam 自带的 *在所有其他设备上退出登录*。

**如实说明的局限**：这是一个人的个人项目，不是 Valve 制作的，也与 Valve 无关，自动化操作账号可能违反 Steam 的规定。使用风险自负。
