- [x] Очередь торговой площадки по предметам, цена и средняя вместе

- [x] Сложность реалистичного режима взята из реального времени прохождения (1.5.6)
- [x] Меньше видеопамяти, нет постоянной перерисовки в простое и меньший размер загрузки (1.5.7)
- [x] Режим малого потребления памяти для слабых компьютеров (1.5.8)
- [x] Один лёгкий таймер вместо бесконечных анимаций (1.5.9)
- [x] Аккаунты и задания (1.6.0): первый щелчок по аккаунту переключает на него, то, что работает или завершилось на каждом аккаунте, видно в верхней панели и в списке аккаунтов, «Старт» и «Стоп» следуют состоянию задания на каждой странице, реалистичный режим открывает достижения от самых частых к самым редким, а быстрый режим держит игры, уже перешагнувшие порог, пока остальные подтягиваются к нему
- [ ] Меньший размер загрузки
- [ ] Ещё меньшая нагрузка на видеокарту и видеопамять
- [ ] Ещё меньшее потребление памяти (RAM)
- [ ] Остальные страницы, перестроенные по макету, по одной на выпуск
- [ ] **Linux и macOS: нужна помощь.** Я не могу проверить ни одну из систем. Если пользователи этих систем согласятся тестировать сборки, я их сделаю; без тестировщиков не трогаю.
- Отказались: переписывать на другом языке или фреймворке (Tauri, Wails, Rust). Это изучалось, выигрыш не оправдывает риск для функций и внешнего вида. SteamEdge остаётся на Electron. Порядок: сначала размер загрузки, затем видеопамять, затем RAM.

Ничто из этого не обещание. Это личный проект, и список меняется вместе с моими приоритетами.
