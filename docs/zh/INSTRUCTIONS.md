# 設定 - 完整說明

[English](../en/INSTRUCTIONS.md) · [Türkçe](../tr/INSTRUCTIONS.md) · [Deutsch](../de/INSTRUCTIONS.md) · [Español](../es/INSTRUCTIONS.md) · [繁體中文](../zh/INSTRUCTIONS.md)

以右上角的齒輪圖示開啟設定。設定是**整個應用程式共用**的，不分帳戶。每一列都有 **?**，
滑鼠移上去會顯示與本頁相同的說明。

變更會立即儲存。**恢復預設值**位於畫面上方。

## 一般

| 設定 | 預設 | 作用 |
|---|---|---|
| **應用程式語言** | Türkçe | English、Türkçe、Deutsch、Español、繁體中文。變更後應用程式會重新載入。 |
| **啟動頁面** | 總覽 | 啟動時開啟哪個分頁。 |
| **介面密度** | 寬鬆 | 緊湊會降低列高，單一畫面約可多容納三分之一。 |
| **時間格式** | 24 小時 | 套用於工作階段計時、記錄時間與安靜時段。 |
| **隨 Windows 啟動** | 關閉 | 登入時靜默啟動 SteamEdge 到系統匣。 |
| **關閉時最小化至系統匣** | 關閉 | 關閉視窗後農場仍在背景繼續。 |
| **阻止睡眠** | 關閉 | farm 或提升時數期間，避免電腦睡眠與螢幕鎖定。 |
| **啟動時收合側邊欄** | 關閉 | 僅顯示圖示；內容區域多出 128 像素。 |

### 備份

| 設定 | 預設 | 作用 |
|---|---|---|
| **匯出／匯入** | - | 將所有偏好設定與累計統計寫入單一 `.json`。**登入權杖與已儲存帳戶刻意排除**，因此檔案可安心放在雲端。 |
| **記住的資料保留多久** | 90 天 | 適用於佇列順序、移除的遊戲與成就紀錄。過期項目會在啟動時刪除。你的設定不受影響。 |

### 危險區域

**刪除所有資料**會移除工作階段、已儲存帳戶、設定、統計與價格快取，並回到登入畫面。
你的 Steam 帳戶不受影響。需要兩次確認。

## 卡牌掉落

| 設定 | 預設 | 作用 |
|---|---|---|
| **預設優先模式** | 依序 | 分頁以哪個模式開啟。 |
| **佇列預設排序** | 預設 | 佇列開啟時依哪個欄位排序。 |
| **同時最多遊戲數** | 10 | 有多少遊戲被視為同時執行。Steam 用戶端的已知上限為 32，這是伺服器端行為，並非本應用程式的限制。數值越低越省資源。 |
| **每款遊戲最長時間** | 5 分鐘 | 時間到後即使沒掉卡也會換下一款。`0` 表示不設限。 |
| **錯誤後重試** | 3 | Steam 連線中斷後重試幾次。每次重試間隔加倍。 |
| **自動重新連線** | 開啟 | 網路或 Steam 中斷後重建工作階段並接續佇列。 |
| **卡牌用盡後前往下一款遊戲** | 開啟 | 關閉時需自行啟動每一款遊戲。 |

### 自動化

| 設定 | 預設 | 作用 |
|---|---|---|
| **自動於市集上架** | 關閉 | 以平均價上架新掉落的卡牌。**會永久改變你的帳戶**，預設關閉。 |
| **背景農場** | 關閉 | 視窗隱藏時略過每秒的介面重繪。引擎不受影響。 |
| **累積時數時解鎖成就** | 關閉 | farm 期間依間隔解鎖成就。**會永久改變你的帳戶。** |
| **卡牌掉落時通知** | 關閉 | 每張卡牌都發桌面通知。 |

## 市集

| 設定 | 預設 | 作用 |
|---|---|---|
| **預設售價** | 平均 | 販售列的起始策略：平均、低於最低價、與最低價相同、立即賣出或自訂。 |
| **低於幅度** | 1 分 | 「低於最低價」要比最便宜掛單低多少。數值小保住利潤，數值大成交更快。 |
| **批次上架最多物品** | 50 | 數值過高可能觸發 Steam 的暫時限制。 |
| **掛單簿深度** | 5 | 詳細面板列出幾個價格層級。 |
| **價格更新間隔** | 15 分鐘 | 庫存分頁開啟時價格重新取得的頻率。 |
| **自動更新價格** | 關閉 | 啟用上述間隔。 |
| **賣出前先確認** | 開啟 | 上架前顯示物品數量、總價與淨價。 |
| **賣出時兩段式確認** | 關閉 | 批次販售時要求 Steam Guard 行動驗證碼。 |
| **價格下跌提醒** | 關閉 | 物品跌破近期中位數時通知你。 |

> **價格永遠與 Steam 一致。** 清單欄位中沒有貨幣換算，也沒有扣除手續費。顯示的金額
> 與 Steam 市集頁面上的完全相同。扣除 Steam 手續費後實際入帳的淨額，會在販售流程中另外顯示。

## 庫存

| 設定 | 預設 | 作用 |
|---|---|---|
| **預設排序** | 依價值 | 表格開啟時依哪個欄位排序。 |
| **雙擊行為** | 開啟詳細面板 | 雙擊物品時的動作。「立即賣出」會略過確認，請謹慎使用。 |
| **低價值門檻** | 1 | 低於此值的物品會變淡，方便批次選取時留意。 |
| **隱藏無法賣出的物品** | 關閉 | 移除優惠券、禮物與不可交易物品。 |
| **隱藏已售出物品** | 開啟 | 已上架物品移至「等待中」，避免重複上架。 |
| **依遊戲分組** | 關閉 | 開啟時即啟用分組。 |
| **緊湊列** | 關閉 | 列高由 60 降為 40 像素。 |

## 時數提升

| 設定 | 預設 | 作用 |
|---|---|---|
| **預設目標時長** | 1 小時 | 分頁以什麼時長開啟。無限制會持續到你手動停止。 |
| **同時最多遊戲數** | 32 | 已知上限。超過的遊戲 Steam 不會計時。 |
| **遊戲啟動間隔** | 5 秒 | 遊戲依此間隔逐一啟動，而非全部同時。 |
| **記住遊戲清單** | 開啟 | 下次啟動時你的選擇已備妥。 |
| **時間到自動停止** | 開啟 | 關閉時遊戲會在超過目標後繼續開著。 |
| **隨機排列遊戲順序** | 關閉 | 每次工作階段順序不同，讓時數平均分配。 |
| **提升時數時暫停farm** | 關閉 | 避免兩個引擎同時對 Steam 運作。 |

### 時數同步

| 設定 | 預設 | 作用 |
|---|---|---|
| **同步遊玩時數** | **關閉** | 分階段拉齊所選遊戲的總時數。見[教學](./TUTORIAL.md#時數同步)。 |
| **目標** | 所選項目中最高者 | 或手動輸入時數，或整個遊戲庫中最高者。 |
| **手動目標時數** | 100 | 僅在目標為「手動輸入時數」時使用。 |

## 成就

| 設定 | 預設 | 作用 |
|---|---|---|
| **解鎖間隔** | 1 秒 | 兩次解鎖之間的等待。實際延遲會在此值附近隨機變動（±40%），因此不會形成固定節奏。較長的選項最高到 90 分鐘。 |
| **預設排序** | 預設 | 依稀有度排序會把最少人解鎖的排在前面。 |
| **安全模式** | 開啟 | 依間隔逐一解鎖。請保持開啟。 |
| **將解鎖分散於一段時間** | 關閉 | 隨機幅度大得多，看起來自然，但耗時長很多。 |
| **單一變更時先確認** | 開啟 | 關閉後可雙擊立即切換。 |
| **我曾勾選「不再詢問」** | 關閉 | 若你關閉過確認視窗，會顯示在這裡。關掉它可讓確認視窗回來。 |

> 解鎖成就會永久改變你的 Steam 帳戶。重新鎖定是可行的，但原本的解鎖日期無法還原。

|---|---|---|
| **顯示桌面通知** | 開啟 | 主開關。關閉後下方所有通知都不顯示，但應用程式內的紀錄仍會保留。 |
| **卡牌農場已開始／已停止** | 開啟 | 包含卡牌數量。 |
| **時數提升已開始／已停止** | 開啟 | 開始、達成目標與停止。 |
| **當成就解鎖時** | 開啟 | |
| **當發生錯誤時** | 開啟 | 連線中斷、登入被拒、販售失敗。不建議關閉。 |
| **通知音效** | 鈴聲 | 23 種音效，全部由應用程式即時產生 - 沒有檔案，沒有授權問題。選擇後會立即播放。 |
| **安靜時段** | 關閉 | 在你設定的時段內不顯示任何通知，包含錯誤。 |

## 隱私與安全

| 設定 | 預設 | 作用 |
|---|---|---|
| **顯示為離線** | 關閉 | 好友看不到你在遊玩；活動不會發佈到個人檔案。 |
| **隱藏遊戲名稱** | 關閉 | 你顯示為在線上，但正在玩哪款遊戲會被隱藏。 |
| **工作階段逾時** | 永不 | 閒置這麼久後登出。執行中的農場或提升會重置計時。 |
| **賣出時兩段式確認** | 關閉 | 批次販售需 Steam Guard 驗證碼。帳戶遭盜用時可保護庫存。 |

## 統計

累計總數：執行時間、掉落卡牌、售出卡牌、提升時數、最佳單日、平均售價與記錄起始時間。
**重設統計**會清空這些數據。

> XP 與徽章數量不會被追蹤 - Steam 不開放 headless 存取。卡牌、販售與時數數據皆為實際量測。

## 進階與資料

| 設定 | 預設 | 作用 |
|---|---|---|
| **記錄層級** | 僅錯誤 | 詳細層級會明顯增加磁碟用量，僅在排查問題時使用。 |
| **保留除錯記錄** | 關閉 | 將所有協定流量寫入 `cache/steamedge.log`。回報問題時請附上。 |
| **硬體加速** | 開啟 | 關閉後顯示卡程序會縮小，在我們的量測中記憶體用量約減少 45 MB，代價是改由處理器繪製。若出現畫面異常或當機也請關閉並重新啟動。 |
| **已使用記憶體** | - | 所有 SteamEdge 程序的總和，並列出各程序用量。讀自程序量測值，並非估算。 |
| **API 請求間隔** | 350 毫秒 | Steam 請求之間的最短間隔。低於 350 毫秒可能觸發暫時限制。 |
| **開啟資料夾** | - | 開啟含有 `settings/` 與 `cache/` 的資料夾。 |
| **清除價格快取** | - | 強制重新取得所有價格。 |

## 帳號卡片

設定頁面右側的面板。顯示 Steam 等級、連線狀態，以及已登入帳號的所有識別碼格式：
**SteamID**（17 位數）、**SteamID2**（`STEAM_1:...`）、**SteamID3**（`[U:1:...]`）、
**帳號編號**、**Hex**，以及個人檔案若有設定則顯示的**自訂網址**。點擊任一列即可複製。
除自訂網址讀取自個人檔案頁面外，其餘皆由 SteamID 在本機計算，不會向 Steam 詢問任何資料。

**複製識別碼**會一次複製全部，**開啟個人檔案**則在瀏覽器中開啟個人檔案。

## 更新

SteamEdge 只在**啟動時檢查一次**發佈清單，且**僅在**有新版本時顯示視窗。若已是最新版本，
不會出現任何提示。

上方工具列中位於鈴鐺與齒輪之間的下載按鈕可隨時重新檢查；在那裡一定會告訴你結果，
包含「已是最新版本」。

程式只讀取版本號，不做其他事。它永遠不會自行下載、安裝或替換自己 - 何時安裝由你決定。
更新方式：將新壓縮檔解壓縮到一個**全新且空白的資料夾**，再把舊的 `settings/` 資料夾複製過去。

## 建議的起始設定

如果你只想讓它直接好用：

- 卡牌掉落：**快速**模式，同時最多遊戲數 **10**
- 成就：**安全模式開啟**，間隔 **1 秒**
- 市集：**賣出前先確認開啟**
- 隱私：若有會注意到的好友，**顯示為離線開啟**
- 通知：為你的睡眠時間**開啟安靜時段**
