# SteamEdge 1.3.2 English edition

This edition uses the upstream 1.3.2 application and runtime with an English
interface by default. It expands the English dictionary for sign-in, account
recovery, inventory and quick actions; translates authentication messages and
notifications before they appear; and includes an English Windows installer.

The original 1.3.2 security update moved to Electron 41.10.7 and patched build
dependencies. The application remains licensed under AGPL-3.0-or-later.

Original SteamEdge creator: Miabeyefendi (Mustafa Ihsan Albayrak).
English edition creator: [@braxffa](https://github.com/braxffa).

The public download contains no saved accounts, Steam sessions or settings.
Never share your personal `settings/` folder.
