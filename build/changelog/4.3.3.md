Card drops with one game left, achievements across restarts, and the visibility choice.

### Fixed

- **One game left in Fast mode: no cards dropped.** Fast mode sent the same open game to Steam again every 10 to 15 seconds. With several games that only keeps them listed, but with a single game it restarted the session each time, so the game never stayed open long enough to drop a card. A single game is now sent once and stays open; it is sent again only when the list of games changes. Sequential mode does the same when one game is left.
- **"Unlock achievements while farming" never reached its turn.** The 20 to 40 minute wait before the next unlock started over every time the app was opened, so an app that is closed and opened every few hours did not unlock anything for a whole night. The time of the last unlock is now kept in the account's file.
- **Choosing the visibility that is already shown did nothing.** When the top bar showed Invisible but Steam had the account online (after switching accounts, for example), pressing Invisible again was ignored. The same choice is now sent to Steam again, which sets it right. The open games send the choice again as well.

### Added

- **`logs/events.log`.** One line each time something changes: the visibility that was sent and the state Steam reports for the account, the games sent to Steam, card farming and hour boosting starting and stopping, achievements unlocked, which settings changed (names only, never values such as a PIN or a proxy address) and every connection event. Nothing is written while nothing changes. It follows the "Log file" setting and never holds a login token.

### Notes

- The account that stays online although it was set to Invisible with two accounts is not explained yet. `events.log` shows what is sent and what Steam answers for each account, which is what is needed to find it.
- The single game and the achievement timer changes were checked with tests and the account files; they were not run against Steam for hours.

**As always:** never share your `settings/` folder - it holds your Steam login token.
