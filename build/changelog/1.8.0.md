The Steam connection keeps a history you can read, the logs have a folder of their own, and the app can start with Windows quietly in the tray.

### Added

- **Connection history** (Settings > Advanced & data > Connection). The last 24 hours of the account on screen: how many times the Steam connection dropped, how long it was down in total, the longest drop, and the time and cause of the last one. While it is down it says since when. A "reconnecting for hours" can now be looked up instead of guessed. **Open** shows the file behind it, `logs/connection.log`: one line for every drop, every wait, every attempt and every return, of every account, with the cause and the number of attempts it took. The history is read back at the next start; a drop the app was closed in ends where the app stopped, so a night with the computer off is not counted as a night without Steam.
- **Start in the tray with Windows** (Settings > General preferences, on by default). When Windows starts SteamEdge, no window opens: the app sits in the tray, connects the saved accounts and resumes the jobs that were left. Click the tray icon to open the window. Starting the app yourself always opens the window, and without a saved sign-in the sign-in screen still comes up. **If "Start with Windows" is on, start SteamEdge once after updating:** it writes the start-up entry with the new switch.

### Fixed

- **Starting SteamEdge while it was already running started a second app for a few seconds.** The second copy was meant to hand over to the open one and end, and it did, but only after it had gone through the whole start: a window, and the logon of every saved account begun next to the open copy's (Steam keeps one session per account). Found while checking the tray start, where the window is not on screen and a second start is likely. The second copy now only brings the open window up.

### Changed

- **The logs have their own folder, `logs/`, next to `settings/` and `cache/`.** Three files: `steamedge.log` (events, at the level chosen under Log file), `connection.log` (the connection history above) and `crash.log` (errors nothing else caught, written whatever the level). The level only applies to `steamedge.log`; Off stops `connection.log` too, the history on screen then lasts until the app closes. The connection lines 1.7.8 wrote to `steamedge.log` at every level are in `connection.log` now; `steamedge.log` keeps them at its own level. Each file is capped (2 MB for `steamedge.log`, 1 MB for the others) and keeps one older part as `.1`. The old `cache/steamedge.log` is moved into the folder at the first start. **Open** next to Log file opens the folder.
- **The Turkish names left in the code are English now.** Variable names, comments, attributes and file names that were still Turkish are English now; only the interface text is translated from Turkish, as before. A broken data file that is set aside is now called `.corrupt` (it was `.bozuk`); files from older versions are renamed once at start, and a file whose new name is taken already is left alone.
- `npm test` runs 63 tests. New: `logger` (the folder, the move of the old file, the level, rotation, crashes, the connection history over a restart and a crash, the old file names). `login-item` covers the tray switch, `window-tray` a window started in the tray and the second copy, `farm-pause-resume` the connection lines.

**As always:** never share your `settings/` folder - it holds your Steam login token.
